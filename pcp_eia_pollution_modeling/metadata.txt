about=PCP-EIA Pollution Modeling is an open-source framework that lets an expert, and the expert's own AI assistant, run pre-integrated environmental models inside QGIS under supervision. Every step is a Processing algorithm with a supervision level: A runs freely, B needs the expert's confirmation in the QGIS window, C is locked and needs a recorded reason to override. Each run writes a tamper-evident audit log. Models are declared in model cards (JSON), so other teams can add models. First models: AERMOD (US EPA, air) and QUAL2Kw (Washington State Ecology, surface water). A Vietnam rules layer (QCVN thresholds, Circular 95/2025/TT-BNNMT on river load capacity) is planned. The plugin does NOT bundle any model binary: download AERMOD from US EPA and QUAL2Kw from Washington State Ecology yourself and set their paths in Processing settings.
